# Implementation Plan: Clerk Authentication

**Branch**: `002-clerk-auth` | **Date**: 2026-02-07 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/002-clerk-auth/spec.md`

## Summary

Add Clerk-based authentication to FINNISH with email/password and Google OAuth sign-in. Implement three subscription tiers (Free, Pro, Team) stored in Clerk publicMetadata, with auth-aware routing that protects Agent Mode behind Pro tier and Editor Mode behind any auth. Create reusable components for route protection, tier gating, and upgrade prompts.

## Technical Context

**Language/Version**: TypeScript 5.7 / React 18.3 / Vite 6.x
**Primary Dependencies**: @clerk/clerk-react (v5.x), react-router-dom v7, zustand v5
**Storage**: Clerk publicMetadata (subscription tier, usage counts). No database needed for auth alone.
**Testing**: vitest (unit), manual browser testing (E2E when Playwright is set up in Task 25)
**Target Platform**: Web browser (desktop + mobile responsive)
**Project Type**: Single-page web application (SPA)
**Performance Goals**: Auth adds < 500ms to initial page load. Sign-in completes in < 10 seconds.
**Constraints**: Clerk publishable key must be provided via env var. No server-side rendering.
**Scale/Scope**: Single app, initial target ~100 users, scaling to ~10k.

## Implementation Steps

### Step 1: Install & Configure Clerk

1. `npm install @clerk/clerk-react`
2. Create `.env.local` with `VITE_CLERK_PUBLISHABLE_KEY`
3. Add env type to `src/vite-env.d.ts`
4. Wrap `<App />` with `<ClerkProvider>` in `main.tsx`
5. Verify build passes

### Step 2: Create Auth Components

1. Create `src/components/Auth/ProtectedLayout.tsx` - route guard using `useAuth()`
2. Create `src/hooks/useSubscription.ts` - extract tier from Clerk publicMetadata
3. Create `src/components/Auth/ProGate.tsx` - gate Pro-only content
4. Create `src/components/Auth/UpgradeCTA.tsx` - upgrade prompt

### Step 3: Add Auth Routes

1. Add `/sign-in/*` and `/sign-up/*` routes to `App.tsx`
2. Wrap `/agent`, `/editor`, `/editor/:id` in `<ProtectedLayout>`
3. Keep `/` and `/credits` public
4. Add `/*` fallback

### Step 4: Update Welcome Page

1. Add `<SignedIn>` / `<SignedOut>` sections to Welcome header
2. Show `<UserButton>` for authenticated users
3. Show Sign In / Sign Up buttons for unauthenticated users

### Step 5: Gate Agent Mode

1. Wrap AgentMode route with ProGate (in App.tsx routing)
2. Free users see UpgradeCTA instead of Agent Mode

### Step 6: Add Subscription Type

1. Add `SubscriptionTier` type to `src/types/index.ts`

### Step 7: Verify & Test

1. Run `npx tsc --noEmit`
2. Run `NODE_OPTIONS="--max-old-space-size=8192" npm run build`
3. Manual test: public routes, auth redirect, sign-in/up, tier gating, sign-out
